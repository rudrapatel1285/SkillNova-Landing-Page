# SkillNova — Responsive Product Landing Page

A modern responsive landing-page **student UI/UX concept** for a fictional online technology learning platform. Created for an individual Figma + GitHub assignment.

## Preview / run locally
Open `index.html` in any modern browser. No install, build step, or backend required. For a local development server, run `python -m http.server 5500` and open `http://localhost:5500`.

## Features
- Responsive desktop, tablet, and mobile layouts
- Sticky navigation and accessible mobile menu
- Hero with editable CSS-based code illustration
- Four reusable-looking feature cards and three course cards
- Sample testimonial, CTA, and footer
- Keyboard focus styles, semantic sections, reduced-motion support
- No external JavaScript frameworks or image dependencies

## Files
- `index.html` — semantic landing-page markup
- `styles.css` — design tokens, components, responsive layouts
- `script.js` — mobile navigation and current copyright year
- `FIGMA_DESIGN_GUIDE.md` — detailed Figma component and Auto Layout build instructions
- `SUBMISSION.md` — explanation and GitHub submission steps

## Design system
Primary `#6855EF`; text `#17223C`; secondary text `#66718A`; lavender `#F2EFFF`. Heading font **Manrope**; body font **DM Sans**. Fonts load from Google Fonts; local system fallbacks are included.

## GitHub Pages deployment
1. Create a **public** GitHub repository named `skillnova-landing-page`.
2. Upload these files to the repository root and commit them.
3. Open repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish; copy the provided URL.
5. Submit your **repository URL** in the class Google Sheet. Also provide your Figma URL if your instructor requests it.

## Scope and honesty
SkillNova is fictional. Courses and quotes are sample content, not real enrollment offerings or testimonials. The "Join the interest list" CTA opens an email draft using a `.example` placeholder address; it does **not** register users or store information. This is a static landing-page demonstration, not a full educational platform.
